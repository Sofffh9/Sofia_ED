# Practica 1 : Haskell + Git + GitHub

## Objetivo  de la practica
Basicamente dejar todo listo para trabajar en Haskell: Installar GHC/GHCup, configurar Git para llevar control del codigo, y subir todo a un repositorio de GitHub para tener respaldo durante el curso 

## Tiempo requerido
Una 1:30 en total
*20* min instalando dependencias 
*20* min instalando GHCup y viendo que GHC/Cabal funciones
*30* min configurando Git
*10* min creando el repo en GitHub y haciendo el primer push

## Comentarios y problemas enfrentados
_ **Problema:** `g++: command not found` al instalar GHC
	**Solucion:** Instale las herramientas de desarrollo son `sudo  dnf install gcc gcc-c++ncurses-devel make xz perl -y`
