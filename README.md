**Diferencia entre Num e Int**  

-Int es un tipo concreto: un entero de tama;o fijo (64 bits) 

-Num es una clase de tipos: un conjunto de operaciones (+,-,*,...)

En resumen: Int es un tipo, Num es una familia de tipos
